# 世界観設定書 ─『魔法少女レニィ☆マギカ』

本作は『魔法少女まどか☆マギカ』の**世界観ルールのみを借用したオリジナル作品**である。
原作キャラクターは一切登場せず、原作固有名詞（ソウルジェム、グリーフシード、魔女、
インキュベーター等）もそのまま使用しない。下記の独自呼称に置き換える。

---

### 案内人「シェル」

白い巻貝を背負った小動物。声は音として発されず、頭の中に直接届く。
一貫して丁寧で穏やかだが、感情を持たない。嘘は一度もつかないが、
**訊かれなかったことは一切答えない**。この性質が物語の全ての悲劇の起点となる。

## 2. 灯守システムの基本ルール

1. 聖灯契約は**「少女」にしか成立しない。**
   案内人が示す条件は「魂の輪郭が未だ定まらぬ者」であり、この世界では統計的に
   思春期の少女のみが該当する。**この条件は本作を通じて一度も破られていない。**
   （＝ 少年である5人は、そもそも契約者ではない。第4章までこの矛盾は伏せられる。）
2. 灯核が翳で満ちると墜化する。墜者となった灯守は元に戻らない。
3. 燼核は有限の消耗品であり、灯守同士の奪い合いが常態化している。
4. 灯守は肉体の損傷では死なない（灯核が無事なら再生する）。灯核の破壊のみが死。
5. 願いの内容は、案内人が**最小コストで成立する解釈**を選ぶ。
   願った者の意図は考慮されない。

## 3. 中心設定 ─ 本作最大の謎

> **なぜ、6人の灯守のうち5人が少年なのか。**

### 表層（プレイヤーの認識、プロローグ〜第3章）

主人公ハルを含む6人の少年と、1人の少女ゲルが灯守として共に戦っている。
少年の灯守は前例がなく、彼ら自身も「自分たちは特別な例外なのだ」と信じている。
ネオだけは事情を知っているが語らない。

### 真相（第4章で開示）

**3年前、ゲル（当時13歳）ただ一人が本物の契約者である。**

家族と住居を翳界に呑まれ、独りで戦い続けた末に限界を迎えたゲルが立てた願いは、
**「もう二度と、独りで戦いたくない」**だった。

案内人シェルは、この願いを**最小コストで**叶えた。すなわち ──
新たな契約者を探すのではなく、**ゲル自身の灯核から溢れた翳を素材に、
彼女の記憶にある「失われた他者」を実体化させた。**

| キャラ | 素材となったゲルの記憶 |
|---|---|
| **ムニ** | 5歳で死んだ**実の弟**。喪われた時のままの姿。 |
| **レニィ** | **同じ弟が、もし生きていたら在ったはずの姿。** ムニと同じ青い髪はこのため。 |
| **ヒュウ** | ゲルを庇って墜化した**年上の灯守の先輩**。緑の髪と赤い瞳。 |
| **ジンパチ** | 崩落した家からゲルを引きずり出し、そのまま死んだ**名も知らぬ誰か**。 |
| **ハル（主人公）** | **該当なし。ゲルの記憶のどこにも存在しない。** |

彼らは人間ではない。ゲルの願いが形を持ったものであり、
**ゲルの灯核が墜化すれば同時に消滅する**。彼らに自前の灯核はなく、
持っている灯核はゲルの灯核から分岐した「写し」に過ぎない。

### 主人公ハルの位置づけ

ハルだけは素材を持たない**空白の器**である。
ゲルの願いが確保した「余白」──誰かが入るための空席──がそのまま形を得たもの。

このためハルは：
- 記憶がない（元になった記憶が存在しないため）
- **灯核が無色透明**（他の5人はゲルの記憶の色に染まっている）
- **ゲルの願いに行動を縛られない唯一の存在**

＝ **本作で唯一、自由意志で結末を選べる者。** これがエンディング分岐の物語的根拠である。

### ネオの位置づけ

**ネオだけは本物の外来者**であり、願いの産物ではない。
外環から本現象を観測して派遣された**執行者**。任務は
「因果を歪めた願いの産物5体の消去」。高圧的な態度は、
消すべき対象に情を持たぬための自己防衛である。

## 4. テーマの構造的実装

抽象的な情感表現ではなく、以下の**構造制約**として実装する。

### 第1章に仕込む3本の伏線（全て第4〜5章で回収）

| ID | 伏線 | 仕込み方 | 回収 |
|---|---|---|---|
| `FS_A` | レニィとムニの同一性 | ムニが寝ぼけてレニィを「にいちゃ……」と呼びかけ、言い直す | 第4章：同じ弟から生まれた二つの姿 |
| `FS_B` | ハルの灯核が無色透明 | 6人の灯核を並べる場面で、ハルのものだけ色がないと指摘され「珍しいね」で流される | 第4章：素材なき空白の器 |
| `FS_C` | ゲルだけ浄化が不完全 | 燼核使用後、ゲルの灯核だけ翳が僅かに残る。本人は「体質だ」と言う | 第4章：翳を5人分の実体に変換し続けているため |

### 必須の構造要件

- **全章の章末はクリフハンガーで終える。**
- **6人のうち1人は必ず明確に裏切り、1人は必ず離脱（決別）する。**
  誰がそうなるかは絆値とフラグで変動する（後述 PLOT.md）。
- **「善意から出た行動が最悪の結果を招く」場面を最低3回配置する。**
  - 第2章：ハルがムニを守ろうと戦闘から外す → ムニの存在希薄化を早める
  - 第3章：ヒュウがゲルの負担を減らそうと燼核を独占 → 疑心の連鎖と分裂を招く
  - 第5章：ゲルを救おうとする行為そのものが、5人の消滅条件を成立させる

## 6. 舞台

- 現代日本の地方都市「**汐灘市（しおなだし）**」。海と丘に挟まれた坂の多い街。
- 3年前に大規模な地盤崩落事故があったことになっている（実際は翳界による侵食）。
- 6人の拠点は、丘の上の**廃校となった旧・汐灘第二中学校**。
