## 1. 判定の仕組み

第五章の最後（`ch05_14`）で、以下の順に評価されます。**上から順に、最初に該当したものが結末になります。**

| 優先 | エンディング | 条件 |
|---|---|---|
| 1 | SECRET「外環の剣」 | ネオの絆 90以上 かつ `neo_identity_revealed` かつ `neo_route` |
| 2 | BAD C「墜ちる」 | 翳 100 |
| 3 | BAD A「刃の理由」 | **裏切った当人**との絆が -1以下 かつ 裏切りが実行済み |
| 4 | BAD B「独りの灯守」 | 絆60以上の相手が 0人 |
| 5 | TRUE「余白に灯る」 | 真相フラグ4種すべて かつ 絆60以上が4人以上 かつ ムニ健在 |
| 6 | GOOD A「明けの星」 | 絆60以上が3人以上 かつ 真相フラグ3種以上 |
| 7 | GOOD B「受け継ぐ手」 | 絆の合計 200以上 かつ 真相フラグが4種未満 |
| 8 | NORMAL「続く朝」 | 上記いずれにも該当しない場合（フォールバック） |

**重要**: BAD系がGOOD系より先に評価されます。絆を完璧に積んでいても、翳が満ちていれば `BAD C` になります。

### 真相フラグ4種

| フラグ | 取得方法 |
|---|---|
| `truth_wish` | `ch04_04` を通過すれば自動 |
| `truth_material` | `ch04_06` を通過すれば自動 |
| `truth_neo_origin` | `ch04_01` を通過すれば自動（`ch03_06` でネオの取引に応じても取得） |
| `truth_haru_blank` | **`ch04_07` で「……それでも、僕はここにいる」を選ぶ必要がある** |

→ **実質のゲートは `truth_haru_blank` ただ一つ。** TRUE と GOOD A を狙うなら、`ch04_07` は必ず1番目を選んでください。

## 2. 共通の基礎知識

### 絆値の設計

- 初期値0、範囲 -20〜100。閾値は 60以上=信頼 / 30〜59=良好 / 0〜29=中立 / -1以下=不和。
- **選択肢の多くはゼロサムです。** 誰かを立てれば誰かが下がります。
- 一方で、**節目のシーンでは全員に無条件の加算が入ります**（初戦闘、シェルの開示、最後の夜など）。
  合計8箇所、1人あたり合計 +34。これが積み上がるので、序盤で多少下げても取り返せます。

### 翳（taint）

上がるのは以下だけです。**BAD C 以外を狙うなら、これらを避けてください。**

| シーン | 上昇量 | 内容 |
|---|---|---|
| `ch01_10` | +4 | 誰かを庇う（4択、どれを選んでも上昇） |
| `ch02_03` | +5 | ゲルについて狩りに出る |
| `ch02_08` | +5 | ネオに槍を構える |
| `ch02_10` | +8 / +3 | 自分が殿を務める / ヒュウに任せる |
| `ch04_07` | +10 / +5 | 空白を拒む / 何も言わない |
| `ch05_02` | +10 | ネオと戦う |
| `ch05_04` | +3 | ひとりで街を見ている |
| `ch05_06` | +15 | 四人を守る（ゲルを助けない） |
| `ch05_10` | +50 | 「願いそのものを断ち切る」 |

合計最大 110。

### 裏切り者・決別者

どちらも自動で決まります（`src/engine/fate.ts`）。

- **裏切り者**: ヒュウが燼核を独占していて絆50未満ならヒュウ。それ以外は hyu / jinpachi / neo で絆が最低の者。
  ジンパチは `named_jinpachi`（`ch04_10` で名を贈る）と `jinpachi_bond_deep`（`ch03_10` で並ぶ）で各+15の下駄を履きます。
- **決別者**: ムニの絆が50未満ならムニ。次にレニィが50未満ならレニィ。どちらも50以上ならゲル。
  → **ムニ健在（TRUE の必須条件）にするには、ムニの絆を50以上にしてください。**

## 3. エンディング別の指針

### TRUE END「余白に灯る」（最難関）

満たすもの: 真相4種 / 絆60以上が4人 / ムニ健在 / 翳100未満 / 裏切り者との絆0以上

1. **`ch04_07` で「……それでも、僕はここにいる」を選ぶ。** これを外すと絶対に到達しません。
2. **ムニの絆を50以上に保つ。** `ch01_04` で手を差し出す、`ch02_03` で付き添う、`ch02_05` で戦線から外す、`ch03_08` で名前を教え直す。
3. **4人を60以上に乗せる。** ネオは切り捨てて構いません（ネオ狙いは SECRET と両立しません）。
   レニィ・ムニ・ゲル・ジンパチを主軸にするのが最も乗せやすい構成です。
4. **裏切り者を作りすぎない。** `ch04_10` で名を贈り、`ch03_10` で並ぶと、裏切り者がヒュウ側に寄ります。
   そのうえでヒュウの絆を0以上に保てば BAD A を回避できます。
5. **翳を極力上げない。** 特に `ch05_06` は「ゲルを助ける」（+0）を選ぶこと。
6. 最終選択（`ch05_10`）は「僕が引き受ける」。

### GOOD END A「明けの星」

TRUE から条件をひとつ落としたもの。**真相3種以上＋絆60以上が3人**。
`ch04_07` を外した場合や、ムニを守りきれなかった場合の受け皿です。狙わずとも自然に落ちてきます。

### GOOD END B「受け継ぐ手」

**絆の合計200以上、かつ `truth_haru_blank` を取らない**。
`ch04_07` で「拒む」か「何も言わない」を選び、あとは満遍なく絆を積んでください。
特定の誰かに集中させず、広く浅く上げるとここに落ちます。

### NORMAL END「続く朝」

どの条件にも当てはまらない場合のフォールバック。狙う必要はありません。

### BAD END A「刃の理由」

**裏切った当人との絆を -1以下にする**のが条件です。
最も簡単なのは、ヒュウを一貫して突き放すこと。`ch03_02` で尾行し、`ch03_04` で糾弾し、
`ch03_05` でジンパチ側に立ち、`ch04_09` で戦線から外す。ヒュウの絆がマイナスに落ちた状態で
第四章の裏切りを迎えると到達します。

### BAD END B「独りの灯守」

**誰ひとり60以上にしない**。ゼロサムの選択肢を毎回バラバラに選び、誰にも肩入れしないと自然に到達します。
節目の加算が入るため、意図的に散らす必要があります。

### BAD END C「墜ちる」

**翳を100まで積む**。上の翳一覧の選択肢をすべて選び、最後に `ch05_10` で
「願いそのものを、彼女の手から断ち切る」（+50）を選べば確実です。
絆がどれだけ高くても、翳が満ちていればこちらが優先されます。

### SECRET END「外環の剣」

**ネオの絆90以上が必須。** これは他の全員を捨てる覚悟が要ります。

| シーン | 選ぶもの | ネオ |
|---|---|---|
| `ch02_08` | 「教えてほしい」（構えを解く） | +12 |
| `ch03_06` | 取引に応じる | +15 |
| `ch04_01` | 何も言わない | +10 |
| `ch04_12` | 送り出す | +10 |
| `ch04_13` | 「まだ決めない」 | +3 |
| `ch05_01` | ネオを探す | +6 |
| `ch05_02` | **「終わったら、あなたと外環へ行く」**（ネオの絆40以上が表示条件） | +32 |
| `ch05_03` | （自動・`neo_ally` 成立時） | +8 |
| `ch05_04` | （節目の加算） | +3 |

合計 +99。`ch05_02` の選択肢は**ネオの絆が40未満だと表示されません**。
第三章までに40を超えておく必要があります。

最終選択（`ch05_10`）で「ネオと共に、この因果ごと外環へ持っていく」が現れます。

## 4. 周回の目安

- 1周目: 素直に選ぶ → GOOD A か NORMAL に落ちます。
- 2周目: `ch04_07` を意識して TRUE を狙う。
- 3周目: ネオ一本に絞って SECRET。
- 4周目以降: BAD 3種の回収。スキップ機能（既読のみ／未読も可）で高速に回れます。

到達済みエンディングはタイトル画面の「エンディング一覧」で、CG・BGMは「回想」で、
通過したシーンは「ルート分岐図」で確認できます。
