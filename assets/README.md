# アセット制作ガイド（グラフィック / BGM 担当向け）

このディレクトリは **Codex（グラフィック・BGM担当）と、シナリオ・実装担当の分担境界**です。
シナリオ／実装側はアセットを一切生成しません。**現在置かれているファイルは全てプレースホルダ**であり、
同じパス・同じファイル名で本物に差し替えるだけでゲームに反映されます。

読むべきファイルはこの2つだけです。

1. **`ASSET_MANIFEST.json`** — 必要なアセットの完全なリスト（これが唯一の正）
2. **本ファイル** — 命名規則と差し替え手順

---

## 1. 作業手順

1. `ASSET_MANIFEST.json` を開く。`assets` 配列の各エントリが1アセットに対応する。
2. 各エントリの以下を読む。
   - `path` — **このパスに、この名前で置く**（変更しないこと）
   - `description` — 何を描く／作るかの指示。生成AIを使う場合はこれをプロンプトの素材にする
   - `spec` — 解像度・尺・ループ有無
   - `used_in` — 使用されるシーンID（`docs/PLOT.md` のシーン一覧と対応）
   - `variants` — **存在する場合、複数枚必要**（後述）
3. プレースホルダを上書きする。
4. `npm run lint:assets` を実行し、欠品・パス不一致がないことを確認する。

**マニフェストに無いアセットを追加しても読み込まれません。** 追加・変更が必要な場合は
`ASSET_MANIFEST.json` の該当エントリを編集してください（実装側がマニフェスト経由でのみ解決するため、
マニフェストを直せばコード変更は不要です）。

---

## 2. 命名規則

| 種別 | 規則 | 例 |
|---|---|---|
| 背景 | `bg_<場所>_<時間帯>` | `bg_school_rooftop_night` |
| 立ち絵 | `sp_<キャラid>_<表情>` | `sp_geru_special` |
| イベントCG | `cg_<連番2桁>_<内容>` | `cg_03_six_cores` |
| BGM | `bgm_<用途>[_<連番2桁>]` | `bgm_battle_02` |
| SE | `se_<内容>` | `se_shatter` |

キャラクターID: `haru` / `renny` / `hyu` / `jinpachi` / `muni` / `geru` / `neo` / `shell`

表情ID（`shell` を除く全キャラ共通・各6種）:
`normal` / `smile` / `sad` / `angry` / `surprised` / `special`
※ `shell` のみ `normal` / `tilt` / `glow` の3種

---

## 3. 仕様

| 種別 | 解像度 / 尺 | 形式 | 備考 |
|---|---|---|---|
| 背景 | 1920x1080 | PNG | 1280x720基準で表示。周囲に少し余白を持たせる |
| 立ち絵 | 800x1400 | PNG（アルファ必須） | 腰から上。**全表情で頭部の位置を厳密に固定すること**（差分切替でズレると破綻する） |
| CG | 1920x1080 | PNG | |
| BGM | 各エントリの `spec.length` | OGG | **ループ必須**。継ぎ目を無音にしない。冒頭2秒以内に主題が立ち上がること |
| SE | 0.1〜3.0秒 | OGG | ループなし |

## 4. `variants` があるアセット（複数枚必要）

裏切り者・決別者はプレイヤーの選択で変動するため、CG が複数パターン必要です。
`path` の拡張子の前に `_<variant>` を挿入したファイル名で用意してください。

| ID | 必要枚数 | ファイル名 |
|---|---|---|
| `cg_12_betrayal` | 3 | `cg_12_betrayal_hyu.png` / `cg_12_betrayal_jinpachi.png` / `cg_12_betrayal_neo.png` |
| `cg_13_farewell` | 3 | `cg_13_farewell_muni.png` / `cg_13_farewell_renny.png` / `cg_13_farewell_geru.png` |

## 5. アートディレクション（厳守事項）

- **全体**: 彩度低め。灯守形態と翳界だけ彩度を上げ、日常との落差を作る。
- **レニィとムニは同系統の青を意図的に共有する。** これは物語上の伏線であり、偶然に見えてはいけないが、
  第1章の時点で答えが割れるほど露骨でもいけない。
- **ハルは全キャラ中で最も彩度が低い。** 「空白の器」であることの視覚的表現。
- **ネオだけは他6人と様式が異なる。** 異世界の意匠。制服姿を持たない。
- **`bg_school_rooftop_day` と `bg_school_rooftop_night` は完全に同一アングル**で、光と空だけを差し替える。
- **`bg_epilogue_dawn` は本作で唯一、明確に暖色を使う背景。** ここだけ色温度を上げる。

## 6. 音楽ディレクション（厳守事項）

主題の再利用が物語構造と対応しています。以下のペアは**必ず同一の旋律主題**を使ってください。

| ペア | 関係 |
|---|---|
| `bgm_geru` ↔ `bgm_geru_theme` | 日常版（ピアノ独奏）と真相版（フルオーケストラ）。同一主題 |
| `bgm_despair` ↔ `bgm_hope` | 同一主題の短調版と長調版 |
| `bgm_neo` ↔ `bgm_neo_theme` | 通常版と外環版。**外環版は音階そのものを他曲と変える** |
| `bgm_true` | 上記すべての主題を統合した集大成 |

`bgm_muni`（オルゴール）は、後半で使い回す際に**音が徐々に欠けていく**加工を入れて構いません
（ムニの存在が希薄化していく表現）。必要なら `bgm_muni_broken` としてマニフェストに追加してください。

---

## 7. プレースホルダについて

- 背景・CG・立ち絵: ファイル名を書き込んだ単色 SVG／PNG
- BGM・SE: 無音の短い OGG

すべて `ASSET_MANIFEST.json` の `path` に実在します。**削除せず上書きしてください。**
差し替え前でもゲームは通しで動作します（`npm run dev`）。
